Practice layer

Audit your sheet in 15 minutes:

  1. Make a backup copy first.
  2. Duplicates: select the data, Data > Remove Duplicates (review the columns it uses).
  3. Blanks: filter each column for blanks and fill or mark.
  4. Formats: select the Date column, set one format; select Amount, set Number.
  5. Record counts: rows before, duplicates removed, blanks fixed.

Example result: "120 rows, 4 duplicates removed, 9 blanks fixed, 2 dates corrected."

Level-up layer

The count of problems per type shows where your process leaks. If most issues are blanks, make fields required; if formats, add a template. Do the audit monthly, not just once. Stretch challenge: add a "Data check" cell on a separate sheet using =COUNTBLANK(Sales[Amount]) and =SUMPRODUCT(--ISTEXT(Sales[Amount])), so problems announce themselves. Keep an audit log of what you changed. Next, test your knowledge in the quiz.

Check yourself: After your audit you removed 4 duplicates. Why should you have made a backup first?

Answer: Removing duplicates is destructive and might delete genuine repeat sales. A backup lets you check or undo what was removed.
