Practice layer

Handle each missing value deliberately:

  1. Required (Date, Amount): you must fill them; check the receipt or M-Pesa message.
  2. Truly unknown (for example customer phone): write Unknown or N/A, the same way every time.
  3. Not applicable: write N/A.

Never type a guess such as an average price. Example: if an amount is missing, =COUNTBLANK(C2:C100) tells you how many to chase. Filter for blanks, fix them, and the count returns to 0.

Level-up layer

A blank, a zero and "N/A" mean three different things: unknown, none, and does not apply. Mixing them corrupts averages, since a zero lowers the average while a blank is ignored. Never fill blanks with invented numbers; it produces confident but false results. Where possible, make fields required at entry (a form with mandatory fields). Record who fixed what if several people edit. Next, see a clean and messy sheet side by side.

Check yourself: Why is typing "0" for an unknown amount worse than leaving a visible note like "Unknown"?

Answer: A zero looks like a real value and silently lowers totals and averages. A clear "Unknown" flags the gap so someone can resolve it.
