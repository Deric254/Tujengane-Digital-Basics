Practice layer

Turn a messy range into a proper table:

  1. Put headers in row 1, one fact per column: Date, Item, Qty, Amount.
  2. Click inside the data and press Ctrl+T (Excel) or use Format as Table; in Google Sheets, create a filter with Data > Create a filter.
  3. Tick "My table has headers".

You should see banded rows and filter arrows. New rows join the table automatically. Common slip: a title in row 1 above the headers. Delete it or move it out so headers are the first row.

Level-up layer

Merged cells break sorting, filtering and pivot tables, so avoid them; use "Center across selection" for looks. One row = one event, one column = one kind of fact. Do not put totals inside the data range; keep them above or on another sheet. Never use colour alone to carry meaning, because formulas cannot read colours: add a Status column instead. Name your table (Table Design > Table Name) such as Sales. Next, name files and entries consistently.

Check yourself: Why is a merged cell in a data table a problem, and what is the alternative?

Answer: Merged cells break sorting, filtering and pivots because rows no longer line up. Repeat the value in each row, or use Center Across Selection for appearance.
