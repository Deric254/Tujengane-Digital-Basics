Practice layer

Computer Literacy covers the basics many jobs and studies assume. Check yourself on these:

  1. Can you create a folder, name a file and find it again?
  2. Can you type a letter in Word and save it as a PDF?
  3. Can you tell a safe link from a suspicious one?

If you hesitate on any, that is your starting point. Try each today: open File Explorer, create a folder named Documents_2023, and save a test file in it. Notice how long it takes; that time will fall with practice.

Level-up layer

Fluency comes from repetition, not from watching: do short sessions daily rather than one long one. Learn keyboard shortcuts early (Ctrl+C, Ctrl+V, Ctrl+Z, Ctrl+S) because they compound. Typing without looking is a quiet superpower for assignments. Be honest about gaps; every skilled person started there. Check the course page for current session details.
