Passwords & Two‑Factor Authentication

Strong passwords and 2FA protect your accounts from unauthorized access.

  • Create strong passwords: long, unique, and passphrases work well.
  • Password manager: store and generate secure passwords.
  • Enable 2FA: SMS, authenticator apps, or hardware keys add an extra layer.
Practice layer

Build a strong password and turn on 2FA:

  1. Make a passphrase of four unrelated words and a number, for example kettle-river-moon-47 (do not use this one).
  2. Use a different password for every important account.
  3. In your Google or Microsoft account open Security > 2-Step Verification and turn it on, preferably with an authenticator app.
  4. Save the backup codes somewhere safe.

You should be asked for a code next time you sign in on a new device.

Level-up layer

Length beats cleverness; reusing one password across accounts is the main danger, because one leak opens everything. A password manager remembers them for you, protected by one strong master password. Prefer an authenticator app over SMS where offered, as SIMs can be swapped. Never share the one-time codes, even with someone claiming to be support. Secure your email first, since password resets go there. Check what your phone and browser already offer.

Check yourself: Why is using the same password everywhere dangerous, even if it is long?

Answer: If one site is breached, attackers try that password on your other accounts. Unique passwords limit the damage to one account.
