Practice layer

Do the three projects as a checklist:

  1. Folders: create Business with sub-folders; save a file in it.
  2. Backup: copy that file to a flash disk or Google Drive; open the copy to confirm it works.
  3. Email: send yourself a message with an attachment, then create a folder or label and move it there.
  4. Accessibility: change one setting, for example text size.

Tick each when done. Answer the mini-quiz without looking, then check. Re-do any project that felt hard.

Level-up layer

The aim is doing, not knowing: if a task took you ten minutes today, repeat it tomorrow to see it fall to two. Stretch challenge: set up 2FA on your email account and write your backup routine on a sticky note. Teach one lesson to a friend; explaining exposes gaps. For quiz misses, re-open that lesson and try again on the real computer. Next, a structured course can take you further with Word, Excel and safe internet use.

Check yourself: What is the quickest way to prove your backup actually works?

Answer: Open the backup copy, or restore one file to a different location. If it opens correctly, the backup is usable.
