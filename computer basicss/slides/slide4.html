Software vs Hardware

Hardware is the body; software is the instructions that make it useful.

  • System software — operating systems and drivers that run the machine.
  • Application software — programs you use: browsers, editors, games.
  • Updates keep software secure and add features—don't ignore them.
Practice layer

See the two kinds of software on your machine:

  1. Open Settings > System > About to see your Windows version (system software).
  2. Open Start and scroll the app list: browsers, Word, games are applications.
  3. Go to Settings > Windows Update and choose Check for updates.

You should see either "You're up to date" or a list to install. Restart when asked. Slip: postponing updates for months; schedule them for a time you are not working.

Level-up layer

Drivers are small pieces of system software that let Windows talk to hardware; a missing driver explains a printer or Wi-Fi card that does not work. Install apps only from trusted sources such as the Microsoft Store or official sites, since pirated software often carries malware. Free alternatives exist for many programs, for example LibreOffice for Word. Do not run two antivirus programs at once. Next, learn what an operating system does.

Check yourself: Is a web browser system software or application software?

Answer: Application software. It is a program you use for a task, while the operating system and drivers keep the machine running.
