Peripherals: How You Interact

Peripherals expand your computer: input devices, output devices, and helpers.

Input

  • Keyboard — typing and shortcuts
  • Mouse/Touchpad — point, click, drag
  • Scanner, Microphone, Webcam — capture real-world data

Output

  • Monitor — screen display (resolution matters)
  • Printer, Speakers — make digital things physical or audible
Practice layer

Identify each device as input or output:

  1. Keyboard, mouse, microphone, scanner: input.
  2. Monitor, printer, speakers: output.
  3. Touchscreen and some USB drives: both.

To connect a USB printer: plug it in, wait for Windows to say it is ready, then go to Settings > Bluetooth & devices > Printers & scanners and print a test page. Slip: printer shows offline. Check the cable and power, then remove and re-add it.

Level-up layer

Screen resolution matters because higher resolution shows more content but smaller text; adjust Scale in Settings > System > Display. Use a printer's draft mode to save ink. Mouse alternatives such as a touchpad work fine; learn two-finger scroll. Webcams and microphones need permission in Settings > Privacy; cover or disable them when not needed. Check yourself: Is a touchscreen an input or output device?

Answer: Both. It displays information (output) and detects your touch (input).
