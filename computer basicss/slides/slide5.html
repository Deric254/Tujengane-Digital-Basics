Operating Systems (OS)

An OS manages resources and provides the interface you interact with: Windows, macOS, Linux.

  1. Desktop & Start menu / Dock — launch apps
  2. Taskbar / Menu Bar — see running apps and notifications
  3. Settings / Control Panel — customization and system tools
Practice layer

Tour Windows in five steps:

  1. Click Start (or press the Windows key) and type "Notepad"; press Enter.
  2. Look at the Taskbar: you should see Notepad's icon with a line under it.
  3. Click the clock/network area (right) for notifications and quick settings.
  4. Open Settings with Windows + I.

Common slip: apps lost behind each other; press Alt + Tab to switch, or Windows + D to show the desktop.

Level-up layer

An OS manages memory, files, devices and security so each program does not have to. Different systems feel different but the ideas match: macOS has the Dock and Menu Bar, Linux varies by desktop. Right-click is your friend: it shows options relevant to whatever you point at. Create separate user accounts for different people, and use a standard account for daily work, not administrator. Learn Windows + Shift + S for screenshots.

Check yourself: You have five windows open and cannot find Notepad. What two shortcuts help?

Answer: Alt + Tab cycles through open windows, and the Taskbar shows each running app so you can click it.
