Accessibility & Personalization

Make the computer work for you: zoom, high contrast, text-to-speech, and keyboard shortcuts.

  • Display settings: change text size and brightness for comfort.
  • Assistive tech: screen readers, captions and dictation help many users.
  • Shortcuts: learn a few key shortcuts to save time (Ctrl/Cmd + C/V, Alt+Tab).
Practice layer

Try three accessibility tools in Windows:

  1. Press Windows + I, go to Accessibility > Text size and move the slider.
  2. Press Windows + Plus to open Magnifier; Windows + Esc closes it.
  3. Press Windows + H for voice typing in a text box (needs internet; check it is available on your version).

Learn these shortcuts: Ctrl + C copy, Ctrl + V paste, Ctrl + Z undo, Ctrl + F find. Result: easier reading and faster work. Slip: nothing happens with Windows + H; click inside a text box first.

Level-up layer

Accessibility helps everyone: captions are useful in noisy places, large text helps tired eyes. Night light and brightness reduce eye strain, and the 20-20-20 habit (every 20 minutes, look 20 feet away for 20 seconds) is simple and free. Good document design supports accessibility too: use headings and add alt text to images. Learn one new shortcut each week. Set up your computer the way you want and write down your settings.

Check yourself: You pressed the wrong key and deleted a paragraph. Which shortcut helps?

Answer: Ctrl + Z undoes the last action. Press it repeatedly to step back further.
