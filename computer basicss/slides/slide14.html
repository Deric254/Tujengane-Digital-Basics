Productivity Tools

Get things done with word processors, spreadsheets and presentation tools.

  • Word processors: write, format and share documents.
  • Spreadsheets: simple calculations, lists, and tables for everyday tasks.
  • Presentations: design slides that communicate clearly and simply.
Practice layer

Make a simple monthly expense sheet:

  1. Open Excel (or Google Sheets) and a blank workbook.
  2. Type headers: Date, Item, Amount.
  3. Enter three rows, then in a cell below the amounts type =SUM(C2:C4) and press Enter.
  4. Select the header row, bold it, and save as Expenses_2023-01.

You should see the total update when you change an amount. Slip: the sum shows 0, meaning numbers were typed as text; retype them without letters.

Level-up layer

Word processors: use Styles for headings instead of making text big by hand, then add a table of contents automatically. Spreadsheets: formulas start with =, and a cell reference like C2 updates if the data changes. Presentations: one idea per slide, large text, little decoration. Free equivalents work too: Google Docs, Sheets and Slides, or LibreOffice. Save often with Ctrl+S, and turn on AutoSave if available.

Check yourself: In Excel you type =SUM(C2:C4) and see 0 although the cells contain numbers. What is likely wrong?

Answer: The numbers are probably stored as text. Retype them as plain numbers, or convert them, and the total will calculate.
