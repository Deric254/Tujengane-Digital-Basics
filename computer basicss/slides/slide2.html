Hardware: The Physical Parts

Think of a computer like a kitchen: hardware are the appliances. Here we'll introduce the CPU, RAM, storage and the motherboard.

  • CPU (Central Processing Unit) — the brain that follows instructions.
  • RAM — short-term memory for running programs; faster but temporary.
  • Storage — long-term memory: HDD (spinning) and SSD (fast, no moving parts).
  • Motherboard & Power — the home where parts connect and receive power.

To see yours in Windows: right-click the Start button, choose System (or Settings > System > About). You should see the processor and installed RAM. Press Ctrl+Shift+Esc for Task Manager to watch memory and disk use live. A slow computer with RAM nearly full is a common sign.

Level-up layer

Do not confuse RAM with storage: a laptop with "8 GB" could mean either, so check the label. RAM clears when you switch off, storage does not, which is why unsaved work vanishes in a power cut. Too many open tabs and programs fill RAM. When choosing a computer, prefer an SSD over an old hard disk, and enough RAM for your work. Check what is currently available and compare before buying.

Check yourself: You switch off without saving and your document is gone. Which part holds unsaved work, and why was it lost?

Answer: RAM. It holds work temporarily while programs run, and it clears when power goes off. Saving copies the work to storage.
