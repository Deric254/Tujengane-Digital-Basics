Files & Folders: Stay Organized

Good file habits save time: create folders, name files clearly, and back up important documents.

  • File types — .docx, .pdf, .jpg; use the right app to open them.
  • Extensions & paths — file.txt, C:\Users\... or /home/user/...
  • Search & preview — use search and previews to find files quickly.
Practice layer

Create a tidy folder system:

  1. Open File Explorer (Windows + E), go to Documents.
  2. Right-click > New > Folder; name it Business.
  3. Inside, create Sales, Expenses, Customers.
  4. Save a file with Ctrl+S, choose the folder, name it Sales_2023-01.xlsx.

Turn on extensions: View > Show > File name extensions. Now you see .xlsx, not just the name. Slip: saving to Desktop and losing files; always choose the folder in the Save As window, and check the path shown at the top before you click Save.

Level-up layer

Use few folders with clear names rather than many nested ones; three levels is usually plenty. A file's extension decides which program opens it; renaming .docx to .pdf does not convert it, use Save As or Print to PDF. Press Windows + E, then F2 to rename quickly. Use search at the top of Explorer, and the preview pane (Alt + P) to look without opening. Delete carefully: the Recycle Bin can restore items.

Check yourself: You renamed report.docx to report.pdf but it will not open as a PDF. Why?

Answer: Renaming changes the label, not the contents. To make a real PDF, use File &gt; Save As or Export and choose PDF.
